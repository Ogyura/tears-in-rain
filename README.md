# Tears in Rain Protocol - Техническая документация

## Архитектура проекта

### Компоненты системы
\`\`\`
TearsInRainProtocol (main.py)
├── BattyAgent (agents/batty_agent.py) - ИИ прогнозирование
├── TannhauserGate (modules/tannhauser_gate.py) - Управление ресурсами  
├── EchoesOfOrion (modules/echoes_of_orion.py) - Звуковая диагностика
├── Config (utils/config.py) - Конфигурация
└── Logger (utils/logger.py) - Логирование
\`\`\`

### Принцип работы
1. **BattyAgent** собирает 10 системных метрик каждую секунду
2. **Isolation Forest** анализирует аномалии в реальном времени
3. При риске > порога → **TannhauserGate** применяет ограничения
4. **EchoesOfOrion** создает звуковой ландшафт системы

## Что реализовано

### ✅ BattyAgent - ИИ мониторинг
- Сбор 10 системных метрик (CPU, память, диск, сеть, загрузка, процессы)
- Машинное обучение на Isolation Forest
- Самообучение каждые 100 измерений
- Прогнозирование рисков 0.0-1.0
- Автосохранение/загрузка модели

### ✅ TannhauserGate - Управление ресурсами
- Мониторинг cgroups (CPU, память)
- Динамическое изменение nice values процессов
- Упреждающие ограничения при рисках
- Статистика по пользователям

### ✅ EchoesOfOrion - Звуковая диагностика
- Генерация звукового ландшафта системы
- 6 типов звуков: гул, клики, шуршание, пинги, гармоники
- Аудио-алерты при рисках
- Интуитивная диагностика через звук

### ✅ Инфраструктура
- Асинхронная архитектура (asyncio)
- YAML конфигурация
- Структурированное логирование
- Graceful shutdown
- Автоматическая установка зависимостей

## Собираемые метрики (16 штук)

### Основные системные метрики (10):
1. `cpu_percent` - загрузка CPU (%)
2. `memory_percent` - использование памяти (%)
3. `disk_io_read` - чтение с диска (байты)
4. `disk_io_write` - запись на диск (байты)
5. `network_io_sent` - отправлено по сети (байты)
6. `network_io_recv` - получено по сети (байты)
7. `load_avg[0]` - загрузка системы за 1 мин
8. `load_avg[1]` - загрузка системы за 5 мин
9. `load_avg[2]` - загрузка системы за 15 мин
10. `process_count` - количество процессов

### Дополнительные метрики управления (4):
11. `cpu_usage` (cgroups) - использование CPU через cgroups
12. `memory_current` (cgroups) - потребление памяти через cgroups
13. `nice_values` - приоритеты процессов
14. `user_processes` - статистика процессов по пользователям

### Производные аудио-метрики (2):
15. `disk_activity` - агрегированная дисковая активность (MB)
16. `network_activity` - агрегированная сетевая активность (MB)

## Как запустить проект

### 1. Системные требования
\`\`\`bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3 python3-pip python3-venv python3-dev
sudo apt install libasound2-dev portaudio19-dev build-essential

# CentOS/RHEL
sudo yum install python3 python3-pip python3-devel
sudo yum install alsa-lib-devel portaudio-devel gcc
\`\`\`

### 2. Установка проекта
\`\`\`bash
# Клонирование/распаковка проекта
cd ~/tears-in-rain-protocol

# Создание виртуального окружения
python3 -m venv venv
source venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt

# Создание необходимых директорий
mkdir -p logs models
\`\`\`

### 3. Запуск
\`\`\`bash
# Активация окружения
source venv/bin/activate

# Обычный запуск
python main.py

# Запуск с правами root (рекомендуется)
sudo venv/bin/python main.py

# Запуск в фоне
nohup sudo venv/bin/python main.py > logs/output.log 2>&1 &
\`\`\`

### 4. Мониторинг
\`\`\`bash
# Просмотр логов
tail -f logs/tears_in_rain.log

# Проверка процесса
ps aux | grep "main.py"

# Остановка
kill -TERM <PID>
\`\`\`

### 5. Конфигурация
Редактировать `config/config.yaml`:
\`\`\`yaml
risk_threshold: 0.5          # Порог риска (0.0-1.0)
monitoring_interval: 1.0     # Интервал мониторинга (сек)
metrics_collection_interval: 1.0  # Интервал сбора метрик (сек)
log_level: "INFO"           # Уровень логирования
\`\`\`

## Проверка работы
После запуска система должна:
1. Создать файлы логов в `logs/`
2. Сохранить модели ИИ в `models/`
3. Воспроизводить фоновые звуки системы
4. Логировать метрики каждую секунду
5. Реагировать на высокую нагрузку звуковыми алертами
